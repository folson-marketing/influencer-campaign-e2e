# 数据完整性

以下规则适用于每个阶段。红人数据库最伤人的错误往往是悄悄发生的：一列错位、一个编出来的粉丝数、一行被漏掉。

## 写入前

- **必填字段**：红人资源库每行必须有平台、账号、主页链接；合作进度表每行必须有 Campaign ID、Creator ID、阶段。
- **类型**：粉丝、播放、互动数都是数字（不要写成「1.2w」「12.3K」这样的字符串）；日期是真正的日期；链接完整。
- **去重**：和已有数据比对同平台 + 同账号，以及同一邮箱对应不同账号的情况。合并或标记，不要新建第二行。
- **能在本地先校验就先校验**（比如先用 Python 整理成表检查一遍），再写入在线表格。

## 写入后

- 把刚写入的行从目标位置（飞书多维表格、Google Sheets 或文件）读回来。
- 和预期对比：行数、列是否对齐，并抽查关键字段（账号、粉丝数、邮箱、分数）。
- 发现错位、截断、重复或缺失，先修好再继续，并告诉用户出了什么问题。

## 估算值标注

- 所有估算或替代指标，**在出现的每个地方都直接标注**，对话里和数据库里都要：`约 12,000（估算）`。
- 填写该行的 `数据可信度 Data Confidence`：
  - **已核实**：直接从平台读取或来自官方导出
  - **估算**：由不完整的数据推算（如只有 5 条内容的平均播放）
  - **替代指标**：拿不到原指标，用别的指标代替（如小红书拿不到播放，用点赞 + 收藏代替）
- 展示互动指标时，说明计算方式，如「互动率 3.4% = 近 12 条内容的平均（点赞 + 评论 + 收藏）÷ 粉丝数」。
- 任何由估算值算出来的指标（CPM、ROAS 等）本身也是估算。

## 合理性检查

出现以下情况时标出来给用户看，不要悄悄保留或删除：

| 检查项 | 标记条件 |
|---|---|
| 互动率 | 高于 20%，或粉丝 1 万以上但低于 0.1% |
| 播放与粉丝 | 平均播放超过粉丝数 10 倍，或低于粉丝数的 1% |
| 活跃度 | 有粉丝但近 60 天没有发帖 |
| 联系方式 | 同一邮箱或微信对应两个及以上账号 |
| 增长 | 粉丝数比上次快照涨了 50% 以上 |
| 效果 | CPM 或 ROAS 与本次 Campaign 其他红人相差悬殊（超过中位数 10 倍） |

被标记不等于直接淘汰，有些是正常的（爆款内容、MCN 共用邮箱）。写明原因，让用户决定。

## 不悄悄丢数据

某行或某字段写不进去（工具报错、缺列、校验没通过），说清楚是哪条、为什么，宁可留空也不要猜。

## 数据来源透明

每次采集新数据，都告诉用户：
- 用了什么工具或 actor（如 Apify actor 名称、「浏览器打开小红书搜索页」），
- 具体的搜索词、话题标签或主页链接，
- 返回了多少条结果，保留了多少条。

工具记在 `数据来源 Source`，搜索词记在 `搜索词 Search Query`。
